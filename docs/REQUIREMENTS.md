Аудит сверяет код с разделом **«КЕЙС: VOICE ROUTER»**, страницы 2–3 файла
«HackAlem AI_ Voice Router - гибридный голосовой AI-робот с LLM-слоем выбора сценария.pdf».

находящийся в общей инструкции пример промпта не является отдельной командой приложению.

## Ограничения и объяснимость

- `expected` и ID тестовых реплик не передаются модели. Обработка не ищет
  пользовательскую фразу в размеченном наборе. Примеры в промпте иллюстрируют
  общие границы намерений; исходный промпт при оптимизации не менялся.
- Клиенты, полисы, цены и записи учебные. Реальные записи разговоров для проверки
  не использовались; приложение предлагает номера из mock backend.
- Ключи остаются на сервере, `.env` исключён из Git. Текст и голос обрабатываются
  внешними API; типовые идентификаторы маскируются в ответах и трассировках.
  Этот фильтр не гарантирует удаление любых персональных данных: для показа
  используются только вымышленные сведения.
- Подтверждение привязано к конкретной операции. Исправление или ошибка отменяют
  прежнее подтверждение. Повторное «да» не повторяет выполненное действие.
- При неясном запросе бот переспрашивает; две последовательные неясные реплики
  приводят к учебной передаче оператору. Самооценка объясняющей модели не калибрована
  и не используется как единственное основание для исполнения действия.
- Передача оператору сохраняет контекст, но живого оператора и телефонии нет.
  Оформление реальных полисов, отправка SMS/писем и промышленная авторизация не реализованы.

## Скорость — бонус, не условие сдачи

В PDF ориентиры 500 мс / 1,5 с прямо отделены от обязательных условий сдачи.
В README стартового набора описаны дополнительные баллы за медиану до 1,5/3 секунд.
Это не основание объявлять любой успешный запуск быстрым.

Парный замер показал снижение медианы **диалога** с 2566,5 до 1559,5 мс.
В единственном полном голосовом замере получено **5190 мс** до `playing`
от оценённого конца речи. **Выполнение ориентиров скорости не подтверждено.**
[Сырые измерения и ограничения методики](LATENCY.md).

## Что проверено в репозитории

119 автоматических тестов проходят, включая исходные проверки Telegram,
параллельное чтение, подтверждения, изоляцию веб-сеансов и передачу первого
аудиофрагмента до завершения потока. Ruff и синтаксис JavaScript проверены.
В Chromium дополнительно проверены текстовая запись к врачу с подтверждением,
запись через MediaRecorder, воспроизведение, фоновое объяснение и мобильная ширина 375 px.
Эти UI-проверки используют подмены API; отдельный голосовой прогон использует
настоящий OpenAI API — [его трассировка](measurements/voice-smoke.json).

## Действия команды перед сдачей

Общая инструкция требует отправить итоговый код **в выданный платформой репозиторий
команды**, затем нажать **«Сдать решение»**, заполнить название и описание до дедлайна.
Наличие кода в локальной папке само по себе не является сдачей. Коммит и push
выполняет владелец проекта; в ходе аудита они не выполнялись.

Документ об оборудовании касается зарядки, переходников, драйверов, DHCP и работы
на площадке. По репозиторию нельзя подтвердить эти пункты. После сбоя ноутбука
проверьте микрофон, динамики, зарядку и доступ к API на месте. Системные и сетевые
настройки в ходе аудита не изменялись.
