# Реплики для проверки демо

Искусственные диалоги для повторяемых проверок. Они не описывают реальные
происшествия; адреса условные, телефоны относятся к учебной базе кейса.

| Файл | Что проверяет |
|---|---|
| [chat_demo.json](chat_demo.json) | Статус полиса, запись к врачу и подтверждение изменений. |
| [dialog_regression.json](dialog_regression.json) | Смену темы, страховые вопросы и русский/казахский язык. |
| [handoff_regression.json](handoff_regression.json) | Передачу оператору и возврат к отложенной задаче. |
| [accident_regression.json](accident_regression.json) | Обращение не по теме, затем ДТП, пострадавших и короткий адрес. |

Запуск из корня проекта:

```bash
python src/chat_demo.py --script examples/accident_regression.json --trace
```

Скрипт использует настоящий OpenAI API. Операции с полисами и передача оператору
остаются учебными. Точные входные реплики прежних замеров могут отличаться от
текущих примеров; обезличенные поля в отчётах отмечены отдельно.
